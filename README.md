# terraform-aws-s3-bucket

Terraform module for a secure-by-default Amazon S3 bucket: public access blocked, versioning, encryption, TLS-only policy, lifecycle rules and access logging.

[![Validate](https://github.com/pankajrudrawar/terraform-aws-s3-bucket/actions/workflows/validate.yml/badge.svg)](https://github.com/pankajrudrawar/terraform-aws-s3-bucket/actions/workflows/validate.yml)

## Features

- Block Public Access on and ACLs disabled (`BucketOwnerEnforced`) by default
- Versioning on and SSE-S3 by default, with SSE-KMS and bucket keys available
- Bucket policy that denies non-TLS requests, merged with any policy you supply
- Lifecycle rules defined as a map: transitions, expiration, noncurrent versions, multipart cleanup
- Optional server access logging

## Usage

```hcl
module "s3_bucket" {
  source = "github.com/pankajrudrawar/terraform-aws-s3-bucket"

  bucket_prefix = "example-secure-bucket-"

  versioning_enabled = true
  sse_algorithm      = "AES256"

  lifecycle_rules = {
    archive-old-data = {
      prefix = "archive/"
      transitions = [
        { days = 30, storage_class = "STANDARD_IA" },
        { days = 90, storage_class = "GLACIER" },
      ]
      noncurrent_version_expiration_days = 180
    }
  }

  tags = {
    Environment = "example"
    ManagedBy   = "terraform"
  }
}
```

A complete, runnable configuration is in [`examples/basic`](examples/basic).

## Notes

- Set `bucket` for a fixed name or `bucket_prefix` for a generated one, not both.
- `object_lock_enabled` can only be chosen when the bucket is created.

## Inputs

| Name | Description | Type | Default | Required |
|------|-------------|------|---------|:--------:|
| create | Controls whether any resources are created by this module | `bool` | `true` | no |
| bucket | Name of the bucket. Conflicts with `bucket_prefix` | `string` | `null` | no |
| bucket_prefix | Prefix for a generated bucket name. Conflicts with `bucket` | `string` | `null` | no |
| force_destroy | Whether all objects, including locked ones, are deleted so that the bucket can be destroyed | `bool` | `false` | no |
| object_lock_enabled | Whether S3 Object Lock is enabled. Can only be set when the bucket is created | `bool` | `false` | no |
| block_public_access | Whether all four S3 Block Public Access settings are enabled | `bool` | `true` | no |
| object_ownership | Object ownership: `BucketOwnerEnforced` (ACLs disabled), `BucketOwnerPreferred` or `ObjectWriter` | `string` | `"BucketOwnerEnforced"` | no |
| versioning_enabled | Whether object versioning is enabled | `bool` | `true` | no |
| sse_algorithm | Server-side encryption algorithm: `AES256` or `aws:kms` | `string` | `"AES256"` | no |
| kms_master_key_id | ARN of the KMS key used when `sse_algorithm` is `aws:kms`. Uses the AWS-managed `aws/s3` key when null | `string` | `null` | no |
| bucket_key_enabled | Whether S3 Bucket Keys reduce KMS request costs. Only meaningful with `aws:kms` | `bool` | `true` | no |
| attach_deny_insecure_transport_policy | Whether to attach a statement that denies requests that do not use TLS | `bool` | `true` | no |
| policy | Additional JSON bucket policy that is merged with the policies generated by this module | `string` | `null` | no |
| logging | Server access logging. `target_bucket` receives the logs under `target_prefix` | `object` | `null` | no |
| lifecycle_rules | Map of lifecycle rules keyed by rule ID | `map(object)` | `{}` | no |
| tags | Tags applied to all resources | `map(string)` | `{}` | no |

|------|-------------|

| bucket_domain_name | Bucket domain name, for example `bucket.s3.amazonaws.com` |
| bucket_regional_domain_name | Region-specific bucket domain name |
